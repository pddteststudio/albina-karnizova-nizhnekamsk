# Салон штор Альбины Карнизовой — демонстрационный сайт

Независимый дизайн-концепт персонализированного сайта-каталога для салона штор в Нижнекамске.

## Запуск

В архиве — готовый статический проект на HTML, CSS и JavaScript. Установка Node.js и npm не требуется.

1. Распакуйте архив.
2. Для локального просмотра откройте `index.html` в браузере или запустите `python -m http.server 8000` и перейдите на `http://localhost:8000`.
3. Для публикации на Vercel загрузите содержимое папки в GitHub и подключите репозиторий, выбрав **Framework Preset: Other**. Build Command не нужен.

## Страницы

- `index.html` — главная и подборка опубликованных предложений.
- `catalog.html` — каталог с фильтрами по категории, ткани, цвету, цене, поиском и избранным.
- `product.html?id=simone-354` — карточка товара и запрос.
- `tailor.html` — подбор штор по размерам, живой SVG-эскиз, локальный предпросмотр фото и копирование заявки.
- `fabrics.html` — справочник тканей и фактур.
- `delivery.html` — заявленные условия оплаты и доставки, FAQ.
- `contacts.html` — подтверждённые контакты салона.
- `inquiry.html` — несколько позиций в одном обращении VK, количество и комментарии.

## Как устроено

- `assets/data.js`: примеры товаров и материалы. ВНИМАНИЕ: цены исторические, из публикаций 8–16.11.2026. Нужно подтвердить актуальность и наличие.
- `assets/app.js`: фильтрация, избранное и подбор через localStorage, копирование, конфигуратор и локальные фото.
- `assets/style.css`: адаптивная вёрстка 320px+.
- `assets/*.svg`: оригинальные авторские **иллюстрации**. Они не являются фотографиями конкретных изделий, реальных заказов или шоурума.

## Важные ограничения

- Это независимая демоверсия. Нет CMS, синхронизации с VK Market, эквайринга или автоматической отправки заявок.
- Избранное и подбор сохраняются только в браузере посетителя (localStorage).
- Фото с устройства НЕ отправляются на сервер, их нужно прикрепить в VK вручную.
- Адрес, часы работы, схема 50/50, бесплатная доставка в большинство городов — информация из описания VK, до официальной публикации согласовать с владельцем.
- Из старых справочников могут встречаться иные адреса: по текущему описанию VK используется проспект Мира, 61А.
- До разрешения владельца сайт содержит `noindex`, robots.txt, версельные заголовки и явные пометки о демоверсии. При официальном запуске их нужно пересмотреть.
- Перед реальной коммерческой эксплуатацией заменить иллюстрации согласованными фотографиями салона, подтвердить описания, цены и наличие; добавить политику конфиденциальности, юридические реквизиты, условия покупки/возврата/доставки, актуальные остатки и механизм обновления каталога.
